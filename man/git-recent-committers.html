NAME

git-recent-committers - List committers with at least one commit in the last N days

SYNOPSIS

git-recent-committers [-n days]

DESCRIPTION

Lists people who made at least one commit in the last N days, with their commit count (one line per committer).

OPTIONS

-n days - Use the last days days. Overrides GIT_RECENT_COMMITTERS_DAYS.

ENVIRONMENT

GIT_RECENT_COMMITTERS_DAYS - Default number of days (default 7) when -n is not given.

EXAMPLES

$ git recent-committers
5  Alice
2  Bob

$ git recent-committers -n 14
